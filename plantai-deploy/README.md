# 🌱 PlantAI

Монголын ургамлын өвчин оношлогоо & Хөрсний AI шинжилгээ

- 85+ өвчин, 16 таримал
- Зургаар AI оношлогоо (Claude API)
- Хөрсний шинжилгээ
- Premium / VIP эрхийн систем

## Суулгах

```bash
npm install
npm run dev
```

## Deploy (Vercel)

```bash
npm install -g vercel
vercel
```
